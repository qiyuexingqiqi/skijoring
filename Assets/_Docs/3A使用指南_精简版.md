## 二、刻滑核心公式

```csharp
// 转向时：旋转板子
rb.AddTorque(Vector3.up * turnTorque, ForceMode.Acceleration);

// + 侧向力（向心力）⭐ 任务核心
rb.AddForce(transform.right * carvingForce * steerInput, ForceMode.Acceleration);
```

```csharp
// 方向性阻力：前进低阻力 / 侧向高阻力 = 刻滑感
localVel.z *= 1f - forwardDrag * dt;   // 前进：0.15
localVel.x *= 1f - lateralDrag * dt;  // 侧向：6.0 → 不侧滑只沿弧线切
```

## 四、关键参数速查表

### CarvingController

| 参数 | 值 | 怎么调 |
|------|-----|--------|
| carvingForce | **35** | 核心！转弯弧线感。↑更弯，↓太直 |
| forwardDrag | **0.15** | 原来0.05太小。↑减速快，↓减速慢 |
| lateralDrag | **6** | ↑转弯僵硬不侧滑，↓会侧滑 |
| turnTorque | **20** | 板子旋转速度 |
| speedDependentCarving | **0.6** | 高速转弯太急就降这个 |
| dynamicFriction | **0.05** | 物理材质动摩擦 |
| staticFriction | **0.08** | 物理材质静摩擦 |
| turnInputParamName | **"turnInput"** | ⚠️ 必须和 Animator 一致 |

### SpeedDependentCamera

| 参数 | 值 | 说明 |
|------|-----|------|
| decelerateSmoothTime | **1.2** | 减速平滑时间（防卡顿） |
| maxDistanceOffset | -12 | 最快时镜头距离 |
| maxFOV | 82 | 最快时 FOV |

### B3_FollowCamera 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| ZDamping | **1.0** | 急停防抖关键 |
| YawDamping | **0.4** | 转向延迟流畅 |
| Collider.Strategy | PreserveCameraHeight | 防穿地模式 |
| Collider.IgnoreTag | "Player" | 不与自己碰撞 |

## 五、4 个必须保持的关联

```
关联1: SpeedDependentCamera.targetRigidbody → Snowboard的Rigidbody
      做法：生成 Prefab 自动赋值，或手动拖入

关联2: B3_FollowCamera.Follow/LookAt → Snowboard对象
      做法：把 Snowboard 拖入两个槽位

关联3: 滑雪板 Tag = "Player"
      做法：Inspector → Tag → 选择 Player

关联4: Animator 参数名 = CarvingController.turnInputParamName
      做法：两边都必须是 "turnInput"，大小写一致
```

## 六、测试方法

### 快速测试流程

```
1. Unity 菜单: Tools → Skiing → Setup Camera Test Scene
2. 打开 Assets/Scenes/CameraTestScene.unity
3. 点 ▶ Play
4. 按 WASD 控制
5. 验证清单:
   ✓ 按 W → 前进加速
   ✓ 按 A/D → 弧线转弯（不是原地转）
   ✓ 按 A/D → 小人做压板动画
   ✓ 松手 → 镜头平滑回位
   ✓ 靠障碍物 → 镜头不穿地
```

### 如果动画不工作

```
1. Tools → Skiing → Fix Animation - Reimport FBX
2. Tools → Skiing → Diagnose Animation Issue（看 Console 日志）
3. 手动检查：Animator 窗口拖动 turnInput 值看小人反应
4. 检查 FBX Rig 设置：Animation Type = Humanoid
```

## 七、调参优先级

| 顺序 | 症状 | 调什么 |
|------|------|--------|
| 1 | 转弯没弧线 | carvingForce ↑ |
| 2 | 转弯太急失控 | carvingForce ↓, lateralDrag ↑ |
| 3 | 减速太快/太慢 | forwardDrag ↓/↑ |
| 4 | 镜头急停抖动 | decelerateSmoothTime ↑ |
| 5 | 镜头跟不上转向 | YawDamping ↓ |
| 6 | 动画不播放 | 检查 turnInputParamName 和 Animator 参数名是否一致 |
