## 四、操作步骤

### 步骤 1：导入 Group 2 的 unitypackage

1. 打开 Unity，打开当前项目
2. 在 Project 窗口中，右键 → **Import Package → Custom Package…**
3. 选择 `SkierAnimation_ForTeam3/SkierAnimation_ForTeam3.unitypackage`
4. 点击 Import（全部勾选）

> 导入后，小人的 Prefab 会出现在 `Assets/` 下的某个位置（看 Group 2 的导出路径）。找到它。

### 步骤 2：对照参数名

1. 找到导入的小人 Prefab，双击打开
2. 选中它，找到 **Animator** 组件
3. 双击打开 Animator Controller
4. 在 Animator 窗口左侧找到 **Parameters** 标签
5. 确认 **1D Blend Tree** 的参数名
   - 如果叫 `turnInput` → **完美**，无需任何修改
   - 如果叫别的不一致的名字 → 修改 CarvingController 的 `turnInputParamName` 为与之完全一致的名字（大小写也要一致）

### 步骤 3：设置父子层级

1. 在 Unity 菜单 → **Tools → Skiing → Create Snowboard Prefab (with Camera)**
2. 生成后的 Prefab 在 `Assets/Prefabs/SnowboardWithCamera.prefab`
3. 双击打开 Prefab 编辑模式
4. 把导入的小人 Prefab **拖入 Snowboard 对象下面**，作为子物体
5. **重置小人 Transform**：Position = (0, 0, 0), Rotation = (0, 0, 0), Scale = (1, 1, 1)
6. 保存 Prefab

### 步骤 4：生成测试场景验证

1. 菜单 → **Tools → Skiing → Setup Camera Test Scene**
2. 打开 `Assets/Scenes/CameraTestScene.unity`
3. 把刚才做好的 `SnowboardWithCamera` Prefab 拖入场景（替换掉自动生成的简单滑雪板）
4. 确保 Main Camera 的 **CinemachineBrain** 组件存在
5. 点击 **Play**

## 五、Group 4（遥测组）对接指南

### 你需要我们的什么？

你需要每隔 0.1 秒获取刚体的速度，发送 JSON。

### 怎么获取？

**方法一（推荐）**：通过 CarvingController

```csharp
// 找到场景中的 Snowboard，获取 CarvingController
CarvingController carving = FindObjectOfType<CarvingController>();
float speed = carving.GetCurrentSpeed();  // m/s
```

**方法二**：直接读 Rigidbody

```csharp
// Snowboard 对象上有 Rigidbody
Rigidbody rb = FindObjectOfType<CarvingController>().GetComponent<Rigidbody>();
float speed = rb.velocity.magnitude;  // m/s
```

**方法三**：用 GetComponentInParent（如果你挂在自己的脚本上且是子物体）

```csharp
Rigidbody rb = GetComponentInParent<Rigidbody>();
float speed = rb.velocity.magnitude;
```

### 要注意什么？

- Rigidbody 在 **Snowboard** 上（父物体），不在小人上
- Tag 是 **"Player"**，在 Snowboard 上
- 速度单位：**m/s**（米每秒）
- 建议在 `Update()` 或 `FixedUpdate()` 中读，不要在 `Start()` 中（因为速度还没起来）

### Tag 对齐 ⚠️ 极易翻车

### 地形适配

| 问题 | 建议 |
|------|------|
| 山太陡，滑雪板飞起来 | 降 `forwardForce`（25→15），增 `forwardDrag`（0.15→0.25） |
| 阻力不对，滑不动 | 降 `forwardDrag`（0.15→0.05），增 `forwardForce` |
| 转弯太急在窄S弯失控 | 降 `carvingForce`（35→20），降 `turnTorque`（20→12） |

调参位置：选 Snowboard → Inspector → CarvingController 组件。

## 十、常见问题

**Q: 小人不动画？**
A: 检查三点：① 小人在 Snowboard 的子物体下面；② `turnInputParamName` 拼写与 Animator 中完全一致（大小写）；③ Animator Controller 中有 1D Blend Tree 且参数名匹配。

**Q: 镜头没有速度联动？**
A: 确认 `SpeedDependentCamera.targetRigidbody` 指向了 Snowboard 的 Rigidbody。重新生成 Prefab 会自动赋值。

**Q: 镜头穿地？**
A: 确认 `CinemachineCollider.CollideAgainst` 包含了地面所在的 Layer（默认 Default=1），且 `IgnoreTag` 设为 "Player"。

**Q: 怎么给 Group 1 交付？**
A: 导出 `SnowboardWithCamera.prefab` 和 `B3_FollowCamera.prefab` 为一个 unitypackage，让 Group 1 导入即可。
