## 二、B3_FollowCamera.prefab 详解

**路径**：`Assets/B3_FollowCamera.prefab`

### 2.1 组成部分

该 Prefab 是一个**嵌套结构**：

```
B3_FollowCamera (根对象)
└── cm (子对象，虚拟相机本体)
    ├── CinemachineVirtualCamera  ← 虚拟相机主组件
    ├── CinemachineTransposer     ← 位置跟随（Body）
    ├── CinemachineComposer       ← 注视构图（Aim）
    ├── CinemachineCollider       ← 防穿墙扩展 ⭐
    └── SpeedDependentCamera     ← 速度联动脚本 ⭐
```

### 2.2 每个组件的作用

#### CinemachineVirtualCamera
- 虚拟相机核心，决定相机的优先级、FOV等基础参数
- **Follow** 和 **LookAt** 槽位需要指定目标（即滑雪板对象）
- **不要删除此组件**

#### CinemachineTransposer（Body组件）
- 控制相机相对目标的**位置偏移**
- `FollowOffset = (0, 2.5, -6.5)` — 相机在目标后上方
- `ZDamping = 1.0` — 前后阻尼（急停时镜头回位是否平滑的关键）
- `YawDamping = 0.4` — 转向时相机延迟跟随，让转弯更流畅
- **可以修改这些Damping值来调整手感**

#### CinemachineComposer（Aim组件）
- 控制相机**看向哪里**
- `LookaheadTime = 0.15` — 预判0.15秒，镜头提前朝运动方向偏
- `SoftZone` 相关 — 软区大小决定镜头"归位"的柔和程度
- **可以修改SoftZone和DeadZone来调整跟随意愿**

#### CinemachineCollider（扩展）⭐ 重要
- 防止相机穿进地面/障碍物
- `CollideAgainst = Default层` — 和地面碰撞
- `IgnoreTag = "Player"` — 不与玩家自身碰撞（否则相机紧贴玩家时会抖动）
- `Strategy = PreserveCameraHeight` — **保持高度模式**，滑雪下坡时不会突然"弹"到雪地上方
- `Damping = 0.4` — 碰撞恢复的平滑度
- **建议不要修改IgnoreTag，除非你的玩家Tag不是"Player"**

#### SpeedDependentCamera（脚本）⭐ 核心功能
- 根据滑雪板速度动态调整相机距离和FOV
- 速度越快 → 相机越远 + FOV越大（速度感）
- 急停时用更长的平滑时间（1.2秒）回位，**防止镜头卡顿**
- `targetRigidbody` — 需要指定滑雪板的Rigidbody组件
- **不要删除此组件，但可以修改Inspector中的数值参数**

### 2.3 使用方式

#### 方式1：直接用Prefab（推荐3A用）
1. 把 `B3_FollowCamera.prefab` 拖入场景
2. 把滑雪板对象拖入虚拟相机的 **Follow** 和 **LookAt** 槽位
3. 把滑雪板的 **Rigidbody** 拖入 **SpeedDependentCamera** 的 `targetRigidbody` 槽位
4. 确保滑雪板的 **Tag** 是 `"Player"`（Collider的IgnoreTag依赖这个）

#### 方式2：合并进自己的Prefa
在3A的滑雪板Prefab内部：
1. 创建一个子对象叫 `FollowCamera`
2. 把 `B3_FollowCamera.prefab` 的组件配置复制过去
3. 在运行时把Follow/LookAt指向父对象

## 三、SpeedDependentCamera.cs 详解

**路径**：`Assets/Scripts/SpeedDependentCamera.cs`

### 3.1 功能

根据目标Rigidbody的速度，在LateUpdate中实时调整：
- **相机距离**（Z轴偏移）：静止=-6.5，最快=-12
- **FOV**：静止=65°，最快=82°
- **高度**（Y轴偏移）：静止=2.5，最快=2.0（略低以增强速度感）

### 3.2 核心机制：非对称平滑

```csharp
// 加速时用0.6秒平滑（快）
// 减速时用1.2秒平滑（慢）→ 防止急停卡顿
float smoothTime = isDecelerating ? decelerateSmoothTime : accelerateSmoothTime;
```

**为什么这样？**
- 玩家加速时，镜头快速拉远，感觉跟得上
- 玩家急停时，镜头缓慢回位，不会突然"抖"一下
- FOV同理：加速时FOV快速放大，减速时FOV缓慢恢复

### 3.3 Inspector可调参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| minDistanceOffset | -6.5 | 静止时相机距离 |
| maxDistanceOffset | -12 | 最快时相机距离 |
| maxSpeed | 30 | 达到最大距离的速度阈值 |
| accelerateSmoothTime | 0.6 | 加速时平滑时间（秒） |
| **decelerateSmoothTime** | **1.2** | 减速时平滑时间（越大越防卡顿） |
| minFOV | 65 | 静止FOV |
| maxFOV | 82 | 最快FOV |
| fovAccelerateSpeed | 3 | FOV加速变化速度 |
| **fovDecelerateSpeed** | **1.5** | FOV减速变化速度 |
| minHeightOffset | 2.5 | 静止高度 |
| maxHeightOffset | 2.0 | 最快高度 |
| heightSmoothTime | 0.8 | 高度平滑时间 |

### 3.4 对接方式

把滑雪板对象的 **Rigidbody** 拖入 `targetRigidbody` 槽位即可。

### 3.5 注意事项

- **不要修改类名**：`class SpeedDependentCamera` 被 `RequireComponent` 依赖
- **不要删除LateUpdate**：速度读取依赖这个
- **不要在Awake外修改transposer引用**：初始化在Awake中完成

## 四、CarvingController.cs 模板详解（3A核心参考）

**路径**：`Assets/Scripts/CarvingController.cs`

### 4.1 这个文件是什么

这是我帮3A写的一个**参考模板**，演示了：
1. 刻滑物理的基本架构
2. 向心力（Carving Force）的实现方式
3. 物理材质的配置方法
4. 方向性阻力系统

**3A可以直接用，也可以完全重写。**

### 4.2 核心刻滑公式

刻滑（Carving）的关键在于**转向时除了旋转，还要施加侧向力**：

```csharp
// 1. 旋转滑雪板
rb.AddTorque(Vector3.up * turnTorque, ForceMode.Acceleration);

// 2. 刻滑侧向力（向心力）⭐ 任务核心
rb.AddForce(transform.right * carvingForce * steerInput, ForceMode.Acceleration);
```

其中：
- `transform.right` 是滑雪板的右侧方向
- 向右转（steerInput=1）时，右侧朝外，产生向右的弧线
- 向左转（steerInput=-1）时，左侧朝外，产生向左的弧线

### 4.3 方向性阻力系统

```csharp
void ApplyDirectionalDrag()
{
    Vector3 localVel = transform.InverseTransformDirection(rb.velocity);

    // 前进方向(z)：低阻力 → 板子顺畅滑行
    localVel.z *= Mathf.Clamp01(1f - forwardDrag * Time.fixedDeltaTime);

    // 侧向(x)：高阻力 → 防止侧滑，只能沿朝向滑行
    localVel.x *= Mathf.Clamp01(1f - lateralDrag * Time.fixedDeltaTime);

    rb.velocity = transform.TransformDirection(localVel);
}
```

**效果**：侧向阻力(6.0)远大于前进阻力(0.15)，所以板子只能沿自身朝向滑行，转向时靠的是刻滑力而非侧滑。

### 4.4 物理材质设置

```csharp
void SetupPhysicsMaterial()
{
    var physMat = new PhysicMaterial("SnowPhysics");
    physMat.dynamicFriction = 0.05f;  // 动摩擦
    physMat.staticFriction = 0.08f;   // 静摩擦
    physMat.bounciness = 0f;           // 无弹性
    collider.material = physMat;
}
```

### 4.5 关键参数说明

| 参数 | 默认值 | 3A应该怎么调 |
|------|--------|-------------|
| forwardForce | 25 | 根据手感调，加速太快/太慢 |
| carvingForce | **35** | ⭐刻滑核心，转弯弧线感的关键，太大转弯急，太小没弧线 |
| turnTorque | 20 | 板子旋转速度，配合carvingForce |
| forwardDrag | 0.15 | 前进阻力，原任务说0.05太小，我改到了0.15 |
| lateralDrag | **6** | 侧向阻力，太高转弯僵硬，太低会侧滑 |
| dynamicFriction | 0.05 | 物理材质动摩擦 |
| staticFriction | 0.08 | 物理材质静摩擦 |
| speedDependentCarving | 0.6 | 速度对刻滑力的影响程度 |

### 4.6 网络信号对接

当前代码使用键盘输入：
```csharp
if (Input.GetKey(KeyCode.A)) steerInput = -1f;
if (Input.GetKey(KeyCode.D)) steerInput = 1f;
```

**替换为网络信号**：
```csharp
// 在某处收到网络转向信号后，直接赋值：
steerInput = 从网络收到的转向值;  // 范围 -1 到 1
```

`steerInput` 变量已经是 -1 到 1 的浮点数，无缝对接网络。

### 4.7 HUD显示

`OnGUI()` 方法在屏幕左上角显示实时信息，包括：
- 当前速度
- 是否在刻滑状态
- 侧向力大小
- 当前阻力参数

**3A可以删除或修改OnGUI()，也可以保留用于调试。**

### 4.8 注意事项

- 刻滑力 `carvingForce` 必须在 `minCarvingSpeed=2` 以上才生效（防止原地打转时也施加侧向力）
- `speedDependentCarving=0.6` 意味着速度越快刻滑力越大，如果感觉高速时转弯太急，可以降低这个值
- **物理材质在 `Start()` 中动态创建**，如果3A的Prefa上已经有物理材质，这个函数会覆盖

## 六、给3A的操作建议

### 6.1 最小改动方案（直接用我的模板）

1. 把 `CarvingController.cs` 重命名为自己的脚本，改掉类名
2. 把滑雪板的Rigidbody相关设置调整为自己需要的值
3. 把 Prefab 生成器 `SnowboardPrefabSetup.cs` 复制一份，改成自己的版本
4. 在 `CameraTestSceneSetup.cs` 的 `CreateSnowboard()` 中替换为自己的控制器

### 6.2 最高自由度方案（完全自己写）

1. 完全重写物理控制器，参考 `CarvingController.cs` 中的刻滑公式和参数设计
2. 自己创建Prefa，手动挂载 `B3_FollowCamera.prefab`
3. 调参直到手感满意

### 6.3 调参优先级建议

如果3A感觉手感不对，按这个顺序排查：

| 顺序 | 症状 | 调整参数 |
|------|------|----------|
| 1 | 转弯没有弧线感，像原地转 | 增大 `carvingForce`（35→45） |
| 2 | 转弯太急，失控感 | 减小 `carvingForce`，增大 `lateralDrag` |
| 3 | 速度上不去 | 增大 `forwardForce`，减小 `forwardDrag` |
| 4 | 松开按键后减速太快 | 减小 `forwardDrag` |
| 5 | 镜头急停时抖动 | 增大 `SpeedDependentCamera.decelerateSmoothTime`（1.2→2.0） |
| 6 | 镜头跟不上转向 | 减小 `CinemachineTransposer.YawDamping`（0.4→0.2） |

## 八、FAQ

**Q：3A的控制器和SpeedDependentCamera在同一对象上会有冲突吗？**
A：不会。物理控制器在 `FixedUpdate()` 中修改Rigidbody的速度/位置，`SpeedDependentCamera` 在 `LateUpdate()` 中读取Rigidbody的速度来调整相机。两者互不干扰。

**Q：可以不删除SnowboardTestController，只把它禁用吗？**
A：可以。在Unity Inspector中把组件前面的勾去掉即可。这样保留了原始测试控制器，方便以后对比。

**Q：SpeedDependentCamera一定要在B3_FollowCamera对象上吗？**
A：不一定。但建议这样放置，因为Prefab结构更清晰。也可以把它放到其他位置，只要能访问到目标Rigidbody即可。

**Q：3A想用Freelook相机而不是Virtual Camera，可以吗？**
A：可以，但需要重新配置。CinemachineFreelook也是虚拟相机的一种，但配置更复杂。如果3A不熟悉，建议继续用B3_FollowCamera的Transposer模式。

**Q：物理材质在哪里看？**
A：在Unity中选中滑雪板对象 → BoxCollider组件 → Material槽位 → 点开可以看到PhysicMaterial的参数。如果在代码中动态创建，参数在 `CarvingController.SetupPhysicsMaterial()` 中。
