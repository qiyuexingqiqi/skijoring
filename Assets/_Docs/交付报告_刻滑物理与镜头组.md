#### CinemachineTransposer（位置跟随组件）

| VerticalDamping | 0.3 | 垂直构图阻尼 |
| ScreenX | 0.5 | 目标在屏幕水平中心 |
| ScreenY | **0.45** | 目标略偏屏幕下方（看到更多前方） |
| DeadZoneWidth | 0.08 | 死区宽度（小→精确跟随） |
| DeadZoneHeight | 0.08 | 死区高度 |
| SoftZoneWidth | 0.5 | 软区宽度（大→归位更柔和） |
| SoftZoneHeight | 0.5 | 软区高度 |

#### CinemachineCollider（防穿墙扩展）⭐ 关键

| 参数 | 值 | 说明 |
|------|-----|------|
| CollideAgainst | Default层(bit 1) | 与Default层碰撞（地面、障碍物） |
| IgnoreTag | "Player" | 不与玩家自身碰撞 |
| MinimumDistanceFromTarget | 0.5 | 相机离目标最近距离 |
| AvoidObstacles | true | 启用障碍物回避 |
| CameraRadius | 0.2 | 相机碰撞球半径 |
| Strategy | 1(PreserveCameraHeight) | **保持相机高度**→防止穿入雪地 |
| MaximumEffort | 4 | 最大回避努力 |

**Strategy=PreserveCameraHeight 的意义**：当相机碰到地面时，不是把相机推到地面上方，而是保持高度不变地拉近到目标。这在滑雪下坡时特别重要——防止镜头突然"弹"到雪地上方。

### 2.2 SpeedDependentCamera.cs — 速度联动镜头

**功能**：根据玩家速度动态调整相机距离、FOV和高度。

#### 核心机制：非对称平滑

```
加速时：镜头快速拉远（accelerateSmoothTime = 0.6s）
减速时：镜头缓慢回位（decelerateSmoothTime = 1.2s）← 解决急停卡顿的关键！
```

#### 参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| minDistanceOffset | -6.5 | 静止时镜头距离 |
| maxDistanceOffset | -12 | 最高速时镜头距离 |
| maxSpeed | 30 | 达到最大距离的速度阈值 |
| accelerateSmoothTime | 0.6 | 加速平滑时间（快） |
| decelerateSmoothTime | **1.2** | 减速平滑时间（慢→防卡顿） |
| minFOV | 65 | 静止FOV |
| maxFOV | 82 | 最高速FOV |
| fovAccelerateSpeed | 3 | FOV加速变化速度 |
| fovDecelerateSpeed | **1.5** | FOV减速变化速度（慢→平滑恢复） |
| minHeightOffset | 2.5 | 静止高度 |
| maxHeightOffset | 2.0 | 最高速高度（略低→速度感） |
| heightSmoothTime | 0.8 | 高度平滑时间 |

#### 工作原理

1. 每帧读取 `targetRigidbody.velocity.magnitude` 获取当前速度
2. 比较当前速度与上一帧速度，判断加速/减速状态
3. **加速时**：用较短的平滑时间(0.6s)，镜头快速拉远+FOV放大
4. **减速时**：用较长的平滑时间(1.2s)，镜头缓慢回位+FOV缓慢缩小
5. 所有过渡使用 `Mathf.SmoothDamp`，确保物理级别的平滑

## 三、3A 刻滑物理 — CarvingController.cs 详细说明

### 3.1 核心概念：什么是Carving（刻滑）？

普通转弯 = 只旋转滑雪板方向 → 板子会侧滑（skidding）
刻滑转弯 = 旋转板子 + 施加侧向力 → 板子沿弧线切线滑行（carving）

关键代码：
```csharp
// 转向时，除了旋转（Torque），还要施加侧向力（Carving Force）
rb.AddTorque(Vector3.up * turnTorque, ForceMode.Acceleration);        // 旋转
rb.AddForce(transform.right * carvingForce * steerInput, ForceMode.Acceleration); // 侧向力！
```

### 3.2 CarvingController 参数详解

#### 前进运动

| 参数 | 值 | 说明 |
|------|-----|------|
| forwardForce | 25 | 前进加速度 |
| maxSpeed | 45 | 最大速度 |
| brakeForce | 15 | 刹车减速度 |
| gravityMultiplier | 1.5 | 下坡重力加成 |

#### 刻滑（转弯）⭐ 核心参数

| 参数 | 值 | 说明 |
|------|-----|------|
| turnTorque | 20 | 转向力矩（让板子旋转） |
| **carvingForce** | **35** | **刻滑侧向力（核心！让转弯有弧线）** |
| speedDependentCarving | 0.6 | 速度对刻滑力的影响程度 |
| minCarvingSpeed | 2 | 最低刻滑速度（低于此速度不施加侧向力） |

#### 阻力/摩擦

| 参数 | 值 | 说明 |
|------|-----|------|
| forwardDrag | **0.15** | 前进阻力（从0.05调高→更真实） |
| lateralDrag | **6** | 侧向阻力（高→防止侧滑→刻滑感强） |
| angularDragValue | 2.5 | 旋转阻力 |
| dynamicFriction | **0.05** | 物理材质动摩擦 |
| staticFriction | **0.08** | 物理材质静摩擦 |

### 3.3 方向性阻力系统

```
前进方向(z)：低阻力(0.15) → 板子可以顺畅滑行
侧向(x)：  高阻力(6.0)  → 板子不会侧滑，只能沿朝向滑行
```

这就是刻滑的物理本质——侧向阻力远大于前进阻力，板子只能沿自身朝向滑行。当施加侧向力时，板子被迫沿弧线运动。

### 3.4 物理材质（PhysicMaterial）

```csharp
dynamicFriction = 0.05   // 动摩擦：板子在雪上滑动的阻力
staticFriction  = 0.08   // 静摩擦：板子静止时启动的阻力
bounciness      = 0      // 弹性：0=不弹跳
frictionCombine = Average // 摩擦混合方式
bounceCombine   = Minimum // 弹性混合方式
```

**为什么Drag从0.05调到0.15？** 原来的0.05太小，板子几乎不会自然减速，感觉像在冰面上。0.15让板子在松开加速键后有自然的减速感，更像在雪上滑行。

## 四、使用指南

### 4.1 如何使用测试场景

1. 回到 Unity Editor，等待脚本编译完成（底部进度条走完）
2. 点击菜单栏 **Tools → Skiing → Setup Camera Test Scene**
3. 在 Project 窗口找到 `Assets/Scenes/CameraTestScene.unity`，双击打开
4. 点击 Play 按钮（▶），用键盘控制：
   - **W/↑**：前进加速
   - **S/↓**：刹车减速
   - **A/←**：左转/左刻滑
   - **D/→**：右转/右刻滑
5. 观察：加速时镜头拉远+FOV变大，急停时镜头平滑回位

### 4.2 如何生成最终交付的滑雪板Prefab

1. 点击菜单栏 **Tools → Skiing → Create Snowboard Prefab (with Camera)**
2. 在 `Assets/Prefabs/SnowboardWithCamera.prefab` 找到生成的Prefab
3. 这个Prefab包含：
   - Snowboard子物体（含Rigidbody + CarvingController + 物理材质）
   - B3_FollowCamera子物体（含CinemachineVirtualCamera + Collider + SpeedDependentCamera）
4. 使用时：把Prefab拖入场景，确保场景中有带CinemachineBrain的Main Camera即可

### 4.3 在已有场景中使用B3_FollowCamera.prefab

1. 把 `Assets/B3_FollowCamera.prefab` 拖入场景
2. 选中场景中的B3_FollowCamera对象
3. 在Inspector中找到 CinemachineVirtualCamera 组件
4. 把滑雪板对象拖入 **Follow** 和 **LookAt** 槽位
5. 找到 SpeedDependentCamera 组件
6. 把滑雪板的 Rigidbody 拖入 **Target Rigidbody** 槽位
7. 确保场景中有 Main Camera 且挂载了 CinemachineBrain 组件

## 五、3A 队员操作指南（精简参考版）

> ⚠️ 以下是我给 3A 的参考模板。3A 应以同文件夹下的 **「3A使用指南_精简版.md」** 为准。

### 5.1 刻滑核心公式（参考 CarvingController.cs）

```csharp
// 转弯时：旋转板子
rb.AddTorque(Vector3.up * turnTorque, ForceMode.Acceleration);

// + 侧向力（向心力）⭐ 任务核心
rb.AddForce(transform.right * carvingForce * steerInput, ForceMode.Acceleration);
```

```csharp
// 方向性阻力：前进阻力小、侧向阻力大 → 刻滑感
localVel.z *= 1f - forwardDrag * dt;    // 前进：低阻力
localVel.x *= 1f - lateralDrag * dt;   // 侧向：高阻力 → 只沿弧线切，不侧滑
```

### 5.2 关键参数

| 参数 | 默认值 | 怎么调 |
|------|--------|--------|
| carvingForce | 35 | 核心！转弯弧线感 |
| forwardDrag | 0.15 | 原来0.05太小改了 |
| lateralDrag | 6 | 太高僵硬，太低侧滑 |
| turnTorque | 20 | 板子旋转速度 |
| speedDependentCarving | 0.6 | 速度越快刻滑力越大 |

### 5.3 测试方法

Unity菜单 → **Tools → Skiing → Setup Camera Test Scene**

打开 `Assets/Scenes/CameraTestScene.unity`，Play，WASD控制。

### 5.4 调参优先级

| 顺序 | 症状 | 调什么 |
|------|------|--------|
| 1 | 转弯没弧线感 | carvingForce ↑ |
| 2 | 转弯太急 | carvingForce ↓，lateralDrag ↑ |
| 3 | 减速太快/太慢 | forwardDrag ↓/↑ |
| 4 | 镜头急停抖动 | decelerateSmoothTime ↑ |
| 5 | 镜头跟不上转向 | YawDamping ↓ |

### 5.5 网络信号对接

只需替换这一处：
```csharp
// 替换前（键盘）
if (Input.GetKey(KeyCode.A)) steerInput = -1f;

// 替换后（网络）
steerInput = 从网络收到的转向值; // -1 到 1
```
