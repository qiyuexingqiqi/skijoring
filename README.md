# 滑雪模拟与多人竞速

使用 Unity 2022.3.62f3c1，打开 `Assets/SnowboardIntegration/Snowfield_Integrated.unity` 进入 Play。

包含单板与双板滑行、上半身转向姿态、装备选择、天气与视角、滑行计时，以及采用 Mirror 的 4–8 人局域网竞速。多人流程提供房间号、准备与倒计时、角色和动画同步、实时排名、检查点复位、终点成绩和房间内再赛。

Windows 程序位于 `Build/Windows/Skijoring.exe`；运行和开发入口见 [多人竞速使用说明](多人竞速使用说明.md)。

Mirror v96.11.4 的源码及许可证随工程提供于 `Assets/Mirror`。通过 Git 克隆时请一并获取 Git LFS 管理的模型资源。
